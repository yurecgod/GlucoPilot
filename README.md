# GlucoPilot AI

**English** · [Українська](#українська) · [Español](#español) · [Deutsch](#deutsch) · [Français](#français)

Offline research diary for adults with diabetes who use a CGM through **xDrip+**. GlucoPilot collects glucose, insulin, food and activity, shows an offline forecast and looks for personal patterns. No account, no cloud, no generative AI.

> **Not a medical device.** Forecasts, ISF, ICR and all calculated values are research estimates, not dosing recommendations. For adults (18+) only. Make treatment decisions with your doctor and use your CGM or xDrip+ for alarms.

## Download
Get the latest APK from **[Releases](../../releases/latest)**. Each release lists the SHA-256 checksum of the APK.

## Requirements
- Android 8.0 or newer (tested on Android 15).
- xDrip+ installed and receiving sensor data.
- Internet only for food search in Open Food Facts.

## Install
1. Download `GlucoPilot-<version>.apk` from Releases.
2. Optional but recommended: compare the file’s SHA-256 with the value in the release notes.
3. Open the file and allow installation from this source when Android asks.
4. In xDrip+ enable **Settings → Inter-app settings → Broadcast locally**.
5. Open GlucoPilot → **Help** for the full guide.

Updates install over the previous version and keep your data. Do not uninstall the app before updating: uninstalling deletes its local history.
